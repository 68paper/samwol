# 삼월 만세 전야 — 1인 플레이 검증판

3.1 운동 테마 주사위 배치 보드게임 『삼월 만세 전야』의 룰 검증용 웹 구현입니다. 사람 1명이 나머지 자리를 컴퓨터에게 맡기고 3 - 5인 게임을 돌려볼 수 있습니다.

## 무엇을 할 수 있나

- **3인 · 4인 · 5인** 게임 진행 (인원별 주사위 개수 · 라운드 수 · 숫자 칸 자리가 자동 적용됩니다)
- **컴퓨터 성향을 플레이어별로 지정** — 소극적 / 균형 / 공격적을 각 자리마다 따로 고를 수 있습니다. 한 명만 공격적으로 두는 식의 조합도 가능합니다
- **페어 · 트리플 · 야찌의 "기여자" 판정 방식 선택** — 자리를 채우면 기여자로 치는 느슨 모드와, 완성을 실제로 이룬 눈을 놓은 사람만 기여자로 치는 엄격 모드 중 고를 수 있습니다
- **확정 점수 방식 선택** — 현행(모든 주사위 개당 +1)과 개정안(완성 칸 개당 +2, 그 외 +1) 중 고를 수 있습니다
- **플레이 로그 다운로드** — 최종 순위, 칸별 배치 순서, 완성 칸 정산 근거, 라운드별 진행 기록을 마크다운 파일로 내려받습니다. 머리말에 플레이어별 성향, 견제 계수, 기여자 판정 방식이 함께 기록됩니다

## 구현된 룰 (v5.3 기준)

|항목|3인|4 - 5인|
|---|---|---|
|주사위|13개|11개|
|라운드|5|4|
|숫자 칸 자리|4|5|

- 매 라운드 **전원 동시 굴림** 후 시작 플레이어부터 순서대로 2개씩 배치
- 모든 칸은 왼쪽부터 채우며, 맨 왼쪽 자리를 차지하면 물꼬 +1
- 한 턴에 같은 칸 2개까지(스트레이트는 1개), 다음 라운드에는 같은 칸에 다시 놓을 수 있음
- 페어 · 트리플 · 야찌의 같은 눈 제약은 **게임 전체** 에 적용
- 놓을 곳이 없으면 놓을 수 있는 만큼만 배치
- 종료 후 일괄 정산 · 총점 동점 시 물꼬 수로 승부

## 기여자 판정 — 느슨 / 엄격
 
페어 · 트리플 · 야찌 칸에서 "완성 보너스를 누가 받는가"는 룰 문서만으로는 한 가지로 정해지지 않습니다.
 
- **느슨** — 그 칸에 자기 주사위를 하나라도 놓았으면 기여자입니다. 트리플 칸에 완성과 무관한 눈을 밀어넣어 방해한 사람도 함께 보너스를 받습니다.
- **엄격** — 실제로 완성을 이룬 눈을 놓은 사람만 기여자입니다. 페어는 자기 눈으로 페어를 만든 사람만, 트리플 · 야찌는 완성시킨 눈을 놓은 사람만 해당합니다. 숫자 칸과 스트레이트는 두 방식이 항상 같습니다(놓인 주사위가 전부 완성에 쓰이므로).

## AI에 대한 주의

컴퓨터는 간단한 휴리스틱으로 움직입니다. 각 배치의 기대 이득(확정 · 물꼬 · 완성 가능성)을 계산하고, 자기 성향 계수만큼 상대의 이득을 빼서 가장 높은 수를 고릅니다. 계수는 소극적 0.15 · 균형 0.55 · 공격적 1.05 입니다.

**여기서 나오는 완성률은 실제 대면 플레이의 예측값이 아닙니다.** 사람은 협상하고 눈치를 보지만 이 AI는 매 수를 독립적으로 계산할 뿐입니다. 특히 야찌처럼 전원이 같은 눈으로 모여야 하는 칸은 AI가 거의 만들어 내지 못합니다. 조건 간 비교(성향을 바꿨을 때, 인원을 바꿨을 때의 방향성)에는 쓸 만하지만, 절대 수치는 대면 플레이테스트로 확인해야 합니다.
