# 삼월 만세 전야 — 1인 플레이 검증판

3.1 운동 테마 주사위 배치 보드게임 『삼월 만세 전야』의 룰 검증용 웹 구현입니다. 사람 1명이 나머지 자리를 컴퓨터에게 맡기고 3 - 5인 게임을 돌려볼 수 있습니다.

## 무엇을 할 수 있나

- **3인 · 4인 · 5인** 게임 진행 (인원별 주사위 개수 · 라운드 수 · 숫자 칸 자리가 자동 적용됩니다)
- **컴퓨터 성향 조절** — 소극적 / 균형 / 공격적. 상대의 이득을 얼마나 깎으려 드는지를 바꿉니다.
- **플레이 로그 다운로드** — 최종 순위, 칸별 배치 순서, 완성 칸 정산 근거, 라운드별 진행 기록을 마크다운 파일로 내려받습니다. 머리말에 플레이어별 성향과 실제 견제 계수가 함께 기록됩니다.

## 구현된 룰 (v5.3 기준)

|항목|3인|4 - 5인|
|---|---|---|
|주사위|13개|11개|
|라운드|5|4|
|숫자 칸 자리|4|5|

- 매 라운드 **전원 동시 굴림** 후 시작 플레이어부터 순서대로 2개씩 배치
- 모든 칸은 왼쪽부터 채우며, 맨 왼쪽 자리를 차지하면 물꼬 +1
- 한 턴에 같은 칸 2개까지(스트레이트는 1개), 다음 라운드에는 같은 칸에 다시 놓을 수 있음
- 페어 · 트리플 · 야찌의 같은 눈 제약은 **게임 전체** 에 적용
- 놓을 곳이 없으면 놓을 수 있는 만큼만 배치
- 종료 후 일괄 정산 · 총점 동점 시 물꼬 수로 승부

## AI에 대한 주의

컴퓨터는 간단한 휴리스틱으로 움직입니다. 각 배치의 기대 이득(확정 · 물꼬 · 완성 가능성)을 계산하고, 자기 성향 계수만큼 상대의 이득을 빼서 가장 높은 수를 고릅니다. 계수는 소극적 0.15 · 균형 0.55 · 공격적 1.05 입니다.

**여기서 나오는 완성률은 실제 대면 플레이의 예측값이 아닙니다.** 사람은 협상하고 눈치를 보지만 이 AI는 매 수를 독립적으로 계산할 뿐입니다. 특히 야찌처럼 전원이 같은 눈으로 모여야 하는 칸은 AI가 거의 만들어 내지 못합니다. 조건 간 비교(성향을 바꿨을 때, 인원을 바꿨을 때의 방향성)에는 쓸 만하지만, 절대 수치는 대면 플레이테스트로 확인해야 합니다.
